# Four-Minute Competition Demo Runbook

## Setup

- Primary URL: `https://fahim-ai-egypt.vercel.app/showcase`
- Backup: a 90-second screen recording of the same path.
- Browser at 100% zoom, Arabic selected, notifications closed.
- Do not sign in during the core demo; use the deterministic route.

## Script

**0:00–0:20 — problem**  
“مريم حفظت قانون نيوتن، لكن لما اتغيّر شكل السؤال استخدمت القوة الكلية في الاتجاه الخطأ. المشكلة ليست نقص فيديو؛ المشكلة أن أحدًا لا يعرف لماذا أخطأت أو هل تغيّر فهمها.”

**0:20–0:50 — source and attempt**  
Show the source, version context and original attempt. State that Fahim starts with the learner’s reasoning—not an answer dump.

**0:50–2:20 — AI is necessary**  
Reveal the misconception as a revisable hypothesis. Show the targeted bilingual intervention, then the learner retry and teach-back. Explain that the intervention changes with the reason behind the error.

**2:20–3:10 — trust and privacy**  
Show claim-level labels, confidence boundary and the privacy-safe teacher signal. State what the system refuses to claim.

**3:10–3:40 — evidence and memory**  
Show the Evidence Graph, mastery dimensions and scheduled delayed recall. Completion is not mastery; retention and transfer are measured later.

**3:40–4:00 — proof and ask**  
Separate working product proof from the planned pilot. Ask for access to one teacher and 12–20 learners for a four-week measured pilot.

## Failure plan

| Failure | Response |
|---|---|
| Network/API issue | Continue on deterministic showcase; it has no AI dependency |
| Auth issue | Do not troubleshoot live; authenticated product is optional evidence |
| Time warning | Jump directly to Evidence Graph, teacher signal and ask |
| Judge asks for outcomes | State that pilot infrastructure exists but no real outcome is claimed yet |
| Judge asks for accreditation | Explain that current artifacts are completion credentials, with institutional issuance planned only after a real agreement |

## Q&A anchors

- **Why not ChatGPT?** Fahim optimizes for a traceable change in understanding, delayed recall and teacher evidence—not answer quality alone.
- **Why GenAI?** The system interprets open reasoning, infers a misconception, adapts the intervention and evaluates teach-back.
- **Who pays?** The learner is the user; parent, teacher or school are candidate buyers/approvers to validate.
- **How is it safe?** Source labels, uncertainty, RLS, privacy-safe aggregation and no default teacher/parent access to chat.
- **What is the moat?** Longitudinal bilingual misconception and learning-evidence data, instructional workflow and teacher adoption—not the base model.
