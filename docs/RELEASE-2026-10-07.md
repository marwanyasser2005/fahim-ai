# Verified learning improvements — 7 October 2026

## Implemented and exercised

- Topic-specific Arabic/English Wikipedia passages, OpenAlex abstracts and Crossref deposited abstracts, rather than portal descriptions presented as evidence. Crossref runs in parallel with bounded timeouts, requires a relevant title and substantive abstract, deduplicates DOI records and does not imply full-text access. API integration follows [official Crossref documentation](https://www.crossref.org/documentation/retrieve-metadata/rest-api/).
- Bounded retrieval cache, output quality screening, repair attempts, and a fallible second citation-support review.
- Learner memory shared by chat and path generation; targeted deterministic teaching interventions.
- Resumable agent questions and explanations, collapsed trace, learner-first layout, open exploration and Cairo typography.
- Multi-stage generated curricula with prerequisites, outcomes, time budgets, meaningful assessment choices, owner-scoped storage and versioned schedule changes.
- On-demand lesson explanations: worked example, misconception, independent practice and transfer task. Saved teaching is reused without another generation. Reading does not mark completion or award mastery.
- Strict server progress reads, explicit failed-save recovery, and optimistic checkpoint updates to avoid silently overwriting a newer round.
- A public AI-quality report that separates contract tests, live synthetic model-reviewed responses, and unmeasured human outcomes.

## Verification

- `npm run check`: 44 test files, 337 tests; TypeScript, lint, build and repository security checks passed.
- `npm run test:e2e`: 10 browser contract scenarios across desktop and mobile passed. These use mocked transport, not live model responses or database isolation proofs.
- Actual production browser rendering: agent, personal-path builder and AI-quality pages passed at 390px and 1440px, without horizontal overflow or JavaScript runtime errors. Screenshots were inspected; this is not a Core Web Vitals measurement.
- A separate real production synthetic session passed agent start, resume without another assessment, choice submission and reasoning submission.
- A real generated path persisted three modules and five assessment questions. Owner read, generated lesson teaching, cached teaching reuse and a versioned schedule change passed. Assessment payload did not expose correct answers.
- Observed request times in that single run: path generation 57.5 seconds; lesson teaching 16.3 seconds; saved lesson retrieval 1.3 seconds. These are observations, not latency guarantees.
- Live synthetic evaluation: 10/12 cases passed model review, with 22 successful generation/review calls. Failures included a provider error and incomplete judge JSON. This is not independent scientific validation or a human learning outcome.
- A 100-request, concurrency-10 GET smoke test had no failures. It does not measure concurrent AI capacity, Core Web Vitals, or provider-failure recovery.
- Human participants: **0**. Educational gain, SME time/cost savings and generated revenue: **unmeasured**.

## Still incomplete in the larger improvement plan

- 100–200 distinct live educational evaluation cases with meaningful learner attempts and independent accuracy review.
- YouTube transcripts, durable PDF/embedding retrieval and systematic source-conflict resolution.
- Independent HTTP link verification and semantic entailment guarantees. Existing citation checks are fallible excerpt checks.
- Fully durable/background path workflows, automatic prerequisite insertion and learned intervention optimization.
- Complete profile integration across every quiz, uploaded file, review and certificate workflow.
- Production cost/quality observability dashboard, broad live regression gates and concurrent AI failure/load tests.
- Full-site language/design audit and measured Core Web Vitals; real signed certificate issuance tested end-to-end in the production browser.

These are remaining implementation work, not merely a request for a human pilot. Existing credential signing and assessment gates are retained; this release does not imply government accreditation.
