# Contributing to Fahim

Fahim is a private, proprietary product repository. Contributions require an approved task and review.

## Development workflow

1. Create a focused branch from `main`.
2. Keep secrets, production exports and learner data out of Git.
3. Add tests for domain, authorization and user-facing behavior.
4. Run `npm run check` and `npm run audit:production`.
5. Document migrations, trust-boundary changes and visible limitations.
6. Request review with screenshots or a short recording for UI changes.

## Product rules

- Do not add placeholder actions or fake operational states.
- Do not claim impact, accuracy, accreditation or partnerships without evidence.
- Preserve Arabic/English behavior, keyboard access, reduced motion and low-bandwidth mode.
- Use the canonical source → attempt → misconception → intervention → retry → evidence → memory vocabulary.
- A certificate is a verifiable completion credential unless a real authorized issuer says otherwise.

## Security

Report vulnerabilities privately. Never include credentials, tokens, student data or production database extracts in an issue, commit, screenshot or test fixture.
